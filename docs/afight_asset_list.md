## 2. プレイヤー立ち絵

**髪型変更と表情差分に対応するため、レイヤー分割方式で作り直す。**

### 2-0. 設計方針

**髪は3レイヤー構造**(髪無しベースを前後の髪で挟む形):

```
[前髪+サイド]   ← 体より手前に描画
[髪無しベース]  ← 顔・耳・首・肩まで完全に描いたもの
[後ろ髪]        ← 体より奥に描画
```

- 前髪と後ろ髪を**別々に選べる**ため、髪型の組み合わせでバリエーションが掛け算で増える
  (例:後ろ髪ツインテール × 前髪パターンA/B/C)
- 髪無しベースは、髪に隠れていた**顔の輪郭・耳・首・肩を描き足す**必要がある

**表情は切り替え方式**(重ね合成ではない):

- 会話場面ではバストアップ画像に切り替えて表示する(ADVゲーム方式)
- 画面下部のパネルを切り替える形で実装(ARENAの ENEMY DATA と同じ仕組みを流用)
- **バストアップも髪を3レイヤーに分ける**ため、髪型変更が会話画面にも反映される

## 12. 制作の優先度メモ

**ゲーム体験への影響が大きい順**(あくまで目安):

1. **立ち絵のレイヤー分割(2節)** — 髪型変更・表情差分・起動シークエンス・メンテナンスモードの
   全てがこれを前提にしている。**初期39点と量は多いが、依存する機能が最も多い**
2. **ペーパードール用の型** — 装備の見た目反映は「クラフトの楽しさ」に直結する
3. **背景(ROOM/CLOSET/ARENA入口)** — 常に目に入る画面。印象を大きく変える
4. **敵機体(まずはアーキタイプ6種)** — 全36体は後回しでよい。まず型ごとの差を出す
5. **BGM(戦闘/拠点)** — 無音である現状のインパクトが大きい
6. **戦闘フィールド背景** — 現状のSVG地形でも成立しているため優先度は中程度
7. **ライバル4体+オーパ** — 出現頻度は低いが、遭遇時の特別感に効く

> **現状はプレースホルダーで全機能が動作している**ため、素材が無くても開発は進む。
> 逆に言えば、**素材ができ次第いつでも差し替えられる**構造になっている
> (TYPE-B/Cの立ち絵を短時間で組み込めたのはこのため)。
