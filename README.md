# A-FIGHT

ブラウザで動く単一HTMLのゲーム。React 18 + Babel standalone をCDNから読み込み、ビルド工程なしで動作する。

**遊ぶ:** https://gibax-commits.github.io/A-FIGHT-/

## 開発上の制約

**画像は必ず `assets/` に外部ファイルとして置く。** HTMLへのbase64埋め込みは行わない。以前は埋め込んでいたが、画像5点でファイルの56%を占め、必要素材は約166点あるため破綻する。外部化により本体は651,706文字から213,344文字まで縮んだ。

**`index.html` を差し替えるときは、ダウンロード前に古いファイルを消しておく。** `index (1).html` のまま上げると、リポジトリに新旧2つが並び、GitHub Pagesは古い `index.html` を配信し続ける。

**JSファイルの分割は簡単ではない。** Babel standalone は各スクリプトを別々のスコープで評価するため、単純に分けると `const` が他のファイルから見えなくなる。分けるなら `window` 経由にするかESモジュール化が必要で、どちらも広範囲の修正になる。

**チャット内プレビューでは画像が表示されない。** 外部ファイル参照はサンドボックス環境で読めないため、動作確認はGitHub Pagesかローカル保存で行う。

## 実装済みの主要システム

戦闘はレーン制の交互行動制。プレイヤーが1行動するたびに敵も1手番動く。AP(行動力)は毎ターン5に回復し、移動・攻撃・スキルで消費する。

アリーナはE〜Sの5ランクで、勝ち進むとランクが上がる。ランクごとに敵の強さの倍率と出現するスキルのプールが変わる。ライバル4体、Sランク防衛戦、世界大会、隠しボスのオーパが用意されている。

セーブはTYPE-A/B/Cごとにスロットが分かれており、キーは `afight_save_v2_{TYPE}`。旧キーからの移行処理が入っている。

詳細は `docs/` の各仕様書を参照。

## ペーパードール (1-C / 未完了)

装備を立ち絵に重ねて表示する仕組み。データ構造は確定済みで、`index.html` の `CHARA_ANCHORS` に実測値が入っている。描画処理への接続と、型(シルエット)画像の用意が残っている。

### 設計

アンカー(接続点)は**キャラクター側**が持ち、アイテム側はアンカー名を指すだけ。逆にすると「武器N個 × TYPE M個」ぶんの定義が必要になるが、この形なら N+M で済む。

各アンカーは位置(比率)と `angle`(その部位が向いている方向)を持つ。左右の部位は角度が符号反転した鏡像の関係になる。アイテム側の `rotate` は、この向きからの差分として書く。

```
回転 = (左右反転コピーなら -item.rotate、通常なら item.rotate) + anchor.angle
```

反転させるのはアイテム自身の回転だけで、`anchor.angle` はそのまま加算する。全体を反転させると、ペア配置のときだけ正しく見えて片側だけに単体配置したときに崩れる。

### 部位 (15)

`HEAD` `HAIR` `TORSO` `WAIST` `R_BACK` `C_BACK` `L_BACK` `R_HAND` `L_HAND` `R_FOREARM` `L_FOREARM` `R_THIGH` `L_THIGH` `R_FOOT` `L_FOOT`

左右対になるのは HAND / FOREARM / THIGH / FOOT / BACK の5組。籠手やブーツのように左右で同じ形の装備は、**画像1枚を反転して2か所に置く**。1アイテムを2画像に分ける必要はない。

### 髪

髪は装備と構造が違い、体を前後から挟む2枚組になる。後ろ髪は最背面(z=2)、前髪は前面(z=34)に置き、同じ髪型として連動して切り替わる。

後ろ髪につむじから頭頂部が描き込まれているのは意図的なもので、最背面に置けばベースの頭部が覆い隠し、前髪との位置合わせがしやすくなる。

`HAIR` アンカーは `HEAD` と別に用意している。イラストの髪は頭部の輪郭より少し上に頂点が来るため、バイザー用の `HEAD`(目のあたり)とは位置が違う。

## tools/paperdoll_lab.html

アンカーの実測とレイヤー配置の確認を行う開発ツール。ダウンロードしてブラウザで開くだけで動く。リポジトリに置いてあるが、ゲーム本体からは参照していない。

- **アンカー定義モード** … 部位を選んでステージをタップすると、その位置にアンカーが移動する
- **レイヤー配置モード** … カテゴリー別のダミーシルエットを重ね、接続点・大きさ・回転・重なり順を調整する

調整結果は `CHARA_ANCHORS` / `DOLL_LAYERS` の形で書き出せる。ページ下部の欄に貼り戻せば復元できる。**リロードすると初期値に戻るため、中断するときは書き出した内容を控えておく。**

ラボはアンカーを実測するための開発ツールであり、ゲームに組み込む想定ではない。プレイヤーがアンカー定義をやり直すことはないため。将来プレイヤーに装備の微調整を許すなら、回転と大きさのスライダーだけを取り出した簡易版になる。

## 既知の課題

**`WEAPON_VISUALS.sword_sample` の `grip` がずれている。** `grip.y` が1205、`naturalHeight` が352で、比率にすると3.42。本来0〜1に収まるべき値が範囲外になっている。v1.31.0でソード画像を差し替えた際、`naturalHeight` は更新されたが `grip` が旧画像の座標のまま残ったもの。画像を解析した結果、柄の位置は (202, 304) 付近。ただし `rotateDeg: 200` も垂直だった旧画像用の値なので、ラボで合わせ直すのが確実。

**`R_THIGH` / `L_THIGH` の `angle` が未設定。** 脚部装甲を扱うときに実測が必要。

**TYPE-B / C の `HAIR` アンカーは暫定値。** 髪が描き込まれた立ち絵のため、髪無しベースができた時点で実測する。
